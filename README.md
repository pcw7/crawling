# crawling

크롤링 연습 프로젝트 모음입니다. 분석 결과는 웹페이지(https://pcw7.github.io/crawling/)에서 볼 수 있습니다.

| 프로젝트 | 내용 | 웹페이지 |
|---|---|---|
| [lotto](lotto/) | 동행복권 로또 6/45 당첨번호 수집, 번호별 출현 빈도와 홀짝 비율 분석 | [보기](https://pcw7.github.io/crawling/lotto/) |

## 원칙

- 수집 전에 robots.txt를 확인하고, 허용된 경로만 수집합니다.
- 요청 사이에 간격을 두어 서버에 부담을 주지 않습니다.
- 수집한 데이터는 레포에 올리지 않습니다. 각 프로젝트의 수집 스크립트로 직접 받을 수 있습니다.
